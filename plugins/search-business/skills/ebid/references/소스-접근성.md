# 소스 접근성 — 공공 발주 정보를 어디서 어떻게 가져올 수 있나

## 목차
- 판정 기준
- 매트릭스
- ebid (한국도로공사 전자조달) — 자동

## 판정 기준

| 판정 | 뜻 |
|---|---|
| 자동가능 | 인증 없이 스크립트로 검색·상세·첨부까지 |
| 부분 | 일부 단계만 자동 (예: 검색은 브라우저, 상세는 API) |
| 수동필요 | 브라우저·사람 개입 필수 |
| 불가 | 기술·정책상 막힘 (DRM, 차단) |
| 미조사 | 아직 시도 안 함 |

## ebid — 자동

- 엔드포인트: 목록 `POST /ui/sp/expro/bidnoti/findListBidNoti.do`, 상세·첨부 `findInfoBidShared.do`
  (물품은 `findInfoResultDetail.do` 폴백), 계약 `findListCntrOpn.do`, 첨부 `POST/GET /raonkDownload/process.dx`
- 세션: `GET /default.do` 로 CSRF 토큰. GUEST 로 전부 가능
- 상태 필터를 비워야 개찰 완료 건까지 검색된다(UI 기본 필터는 진행 중만)
- 발주유형에 따라 첨부가 붙는 API 가 다르다 — 목록 조회는 항상 2단 경로
- 요청 예절: 요청 간 1초, 재시도 2회 (스크립트에 내장)

## 나라장터 — OpenAPI 는 ebid 의 대체 소스로 부적합

- `getDataSetOpnStdBidPblancInfo`: 키워드·기관 파라미터 없음, 날짜 창 31일 상한, 10,000건 절단,
  첨부 필드 없음, `data.go.kr` 키 필요
- 전수 스캔 2회(5,006건·7,709건)에서 한국도로공사 발주 0건 → 도로공사 공고는 ebid 에만 실린다
- 웹(g2b.go.kr)은 미조사. 도로공사 외 기관이 필요해지면 여기부터

## EIASS · 관보 · 뉴스 — 수동

- EIASS: 검색은 실브라우저(반복 호출 차단), 상세 `POST /biz/base/info/eiaInfo.do`, 원문 PDF 는 DRM
- 관보(gwanbo.go.kr): 고급검색 "제목+내용", ezPDF 뷰어에서 본문 추출 가능
- 뉴스: WebSearch → WebFetch. 기관 사이트(ex.co.kr)는 타임아웃 → 브라우저

## 새 소스를 추가할 때

1. 위 매트릭스에 한 줄 추가 (판정은 실측 후에만)
2. 검색·상세·첨부 각 단계의 엔드포인트·인증·제한을 이 문서에 기록
3. 자동가능이면 `scripts/` 에 형제 도구 또는 형제 스킬로 추가, 아니면 방법만 기록
